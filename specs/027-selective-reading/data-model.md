# Artifacts and bindings

A route identifies mandatory files plus triggered lookups. A pattern keeps ID/title/body/exclusion/recipe and one source path. Relocation changes only that path. A measurement records file set, Unicode characters, UTF-8 bytes and line count; it is not a model token trace. An archive keeps metadata version 0.13.2 but is labelled Unreleased with hashes outside default release filenames.
