# Feature Specification: Selective reading for Vietnamizer

**Feature Branch**: `codex/readme-evidence` (reuse authorized dirty worktree)
**Created**: 2026-10-31
**Status**: Approved scope; implementation authorized by the owner's simplification request
**Input**: Simplify and split instructions so agents read only the relevant material; retain meaning-first workflow and all safeguards; no version bump or release.

## User Scenarios & Testing

### User Story 1 — Small correction (Priority: P1)
A one-sentence correction keeps its scope without loading whole-article or voice-transfer procedures.
**Independent Test**: Same work-message route measured before/after; repair a missing result complement using only core and the relevant catalog.
**Acceptance Scenarios**:
1. Given a local error and surrounding context, when correcting it, then retain claims/voice and look up its exception before editing.
2. Given no key/capability, when checking evaluator availability, then continue core without loading the full evaluator contract or claiming a check ran.

### User Story 2 — Article editing and writing (Priority: P2)
An existing professional article and new writing from supplied samples use meaning-first guidance without reading unrelated error catalogs or a source directory.
**Independent Test**: Measure both article routes; inspect safeguards and conditional reads separately.
**Acceptance Scenarios**:
1. Given an article, when outlining/re-expressing, then retain full source and compare meaning both ways.
2. Given supplied samples, when adopting voice, then select evidenced traits without importing the sample's claims or experiences.
3. Given mixed functions or unresolved context, when routing, then consult the resolver rather than load all profiles/cards.

### User Story 3 — Distribution and canonical lookup (Priority: P3)
All 55 patterns remain discoverable from one canonical body each, and package/evaluator bindings still work.
**Independent Test**: Regenerate registry; compare every field except relocated source paths to the incoming registry; validate packages and mutate canonical exclusions.

### Edge Cases
Typography-only genres; protected byte spans; unknown quote status; intentional ellipsis; limited edit scope; no sample; mixed function; model tools unavailable; evaluator failure; historical evidence using old layouts.

## Requirements

- **FR-001**: Keep authority, data boundaries, protected bytes, meaning/voice/scope gates in the always-read entrypoint.
- **FR-002**: Route small edits, article work and supplied-sample work explicitly; no unconditional catalog, resolver or evaluator-contract loads.
- **FR-003**: Preserve all 55 pattern bodies/exclusions; change ownership location without creating duplicate rules.
- **FR-004**: Keep semantics-first article workflow, source traceability, modality/negation/quantity/causality/ambiguity and final review.
- **FR-005**: Preserve incoming changes and README bytes; metadata 0.13.2, Unreleased; archives labelled separately, baseline dist restored.
- **FR-006**: Measure exact files/lines/Unicode characters on the three matching routes; distinguish mandatory and triggered reads, not actual billed tokens.
- **FR-007**: Verify package/registry consumers and review hidden eager loads; report behavioral evaluation pending unless actually run without new rights/cost.

## Success Criteria

- **SC-001**: Each matched route requires fewer instruction characters than its frozen incoming route, including a realistic triggered catalog on the small-edit example.
- **SC-002**: All 55 registry entries retain their previous judgments, exceptions, signals and gates; only source metadata may change.
- **SC-003**: Relevant package, registry and runtime tests pass; historical drift is untouched and disclosed.
- **SC-004**: No version bump, release/install or loss of incoming edits; review findings resolved or explicitly reported.

## Assumptions

Measurements count each required full file once and exclude user prose, tool outputs and caches. Catalog lookup is conditional and can use a heading range when supported. No behavioral-quality improvement is inferred from character savings.
