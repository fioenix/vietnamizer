# Conceptual data model
- Intent: preserve-source (default), adapt-reference (explicit current task request + usable task-supplied reference).
- Reference trait: sample span, genre/reader scope, observed feature, uncertainty/exception; transient, not persisted user identity.
- Source invariant: proposition/referent, quantity, time/order, condition/negation, certainty/commitment, protected bytes.
- Edit: correction -> applicable pattern + No-flag check; adaptation -> requested intent + scoped evidence + permissible structural/tone choice. Both require invariant preservation.
- Disposition: keep, narrow/revert, ask only when missing reference or unresolved relationship prevents a required decision. No score-based action.
