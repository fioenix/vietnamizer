# Editing contract
Preserve-source is selected for ordinary proofreading, vague naturalness requests, samples merely supplied or explicit preservation. Adapt-reference is selected only when the user explicitly asks for that reference voice; lacking usable supplied reference requires requesting it, never external identity lookup. Selection cannot change permission/protected-region/genre gates.

Corrections require patterns; style edits require task authority and scoped reference evidence. A heading/list may only express existing propositions/relations, retaining conditions, qualifications, quantities and order. Register carries intent/traits when the optional existing advisor is used; typed judgments neither veto nor authorize stylistic change. No new runtime fields or calls.
