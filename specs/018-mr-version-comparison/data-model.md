# Data model
Scenario: stable id/mr_id, origin, source/context/request, family, source anchors.
Rubric: required predicates, accepted alternatives, uncertainty, optional opportunities.
Cell: scenario/version, frozen prompt hash, fresh native session, raw paths, schema/argv,
exit/status/time/usage, no-retry reservation. Logical result: worst unresolved/failed
required subscenario; optional opportunities never change mandatory pass counts.
