# Evidence model

RegressionCase: stable MR identifier; source kind (observed AI-edited article/candidate
or synthetic counterexample); full relevant context; original and candidate excerpts;
expected disposition; governing rule; uncertainty; immutable source/output SHA256.
A disposition is a host-authored expectation for development, not a human-gold label
or a numerical acceptance policy. No personal style traits are stored in this model.
SourceSnapshot: exact pre/post canonical files, recipes, registry and package digests.
PreservationManifest: original23,469file paths and SHA256, with final missing/changed list.
