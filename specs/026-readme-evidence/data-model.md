# Evidence data model

- Source: repository-relative unchanged report path and SHA256.
- Regression: ordered MR01-MR12 identifiers, baseline/current version and boolean pass labels; totals derived, not separately hand-entered.
- Voice: comparisonD-C, editorCodex, version0.13.2, judge name, planned8/observed7or8, win/tie/loss/missing counts; missing derived planned-observed and never imputed.
- Theme: frozen named brand-token values with canonical source provenance; no runtime dependency on another repo.
- Artifact: deterministic SVG for public README, PDF/PNG optional local exports; each source/data transformation is reproducible without inference.
