# Selection contract

Root owns intent, five gates and sequence; guide owns choosing a role-compatible form; resolver owns profile/card boundary. A section may choose different rhetorical forms inside one stable profile/card. No domain-based switch or article-fragmentation.

Permission to retain/use question or bạn is not a requirement to introduce it. References justify forms by comparable role/reader relation; topic-heading/question/implicitreader variants may all be valid. Select form that covers all subordinate content and makes existing contrast/task easier to follow; with insufficient benefit retain suitable current form. Explicit owner stylistic instructions still apply within root meaning/genre limits.

Structure can change; preserve every source proposition, modality and relation. Do not add exact count to source-generic noun. No new call, pattern, registryrecipe, API threshold or persisted voice profile.
