# Voice evidence

Sample: author/origin claimed by user, channel, purpose, audience, only relevant short excerpts.
Observation: dimension, scope, quote/example, repeat/exception evidence, strength=observed or
provisional or explicit-request, applicability. Absence never implies a user prohibition.
Revision pair: style vs content change; only applicable style informs current-task preference.
Durable profile is optional user-requested output, not automatic state or runtime discovery.
