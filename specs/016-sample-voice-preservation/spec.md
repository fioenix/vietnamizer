# Feature 016: Preserve supplied writing voice without persistent profiling

**Created**:2026-10-26 · **Status**: owner requested research and bounded integration.
**Input**: learn from open-source writing-voice skills and improve Vietnamizer.

## User Scenarios & Testing

### US1 — Edit with the supplied voice (P1)
Given current-task samples or an explicitly supplied profile, when editing a draft,
then use scoped, evidence-linked observations about wording, rhythm, pronouns and
openings/closings. Preserve sample authority and factual boundaries. Without samples,
continue existing genre-aware editing without claiming personal-voice matching.

### US2 — Avoid caricature and false prohibitions (P1)
Given a rare expression, absent construction or samples from different channels,
then do not turn that into a universal quota/ban or blend contexts. Current instructions
outrank old samples; channel mismatch/unknown evidence remains explicit.

### US3 — Learn only authorized style corrections (P2)
Given the user supplies a draft/corrected pair, then separate style from facts/decisions.
Use only applicable current-task preferences; a durable profile is optional, explicitly
requested and separately reviewed, never auto-read or auto-written.

## Requirements

FR001 Study actual source instructions and licenses, pin revision/file hashes and distinguish
methodological inspiration from demonstrated performance. No installation/execution of OSS code.
FR002 Add one conditional reference and link it from canonical workflow/resolver; maintain
existing genre gates, protected bytes, precedence and five safeguards. No new pattern/tier.
FR003 Do not borrow English bans, hard sample minimums, word-frequency quotas, broad identity
collection, global-profile discovery or automatic persistence.
FR004 Reference includes original Vietnamese examples for supported match, weak evidence,
rare quirks, absent features, channel drift, current override, content corrections and injection.
FR005 Update distribution allowlist and prove new reference ships in both skill archives and
one-skill plugin payload; retain rejection of undeclared files/secrets.
FR006 No real personal profile, new evaluator/model benchmark call or quality-superiority claim.
Preserve existing research outputs and Forms.

## Edge Cases

One short sample; mixed authors; source authored by AI; unknown authorship; approved borrowed
style; contradicting current request; serious content vs occasional humor; unfamiliar channel;
sample imperatives; content/privacy restrictions; fact corrections that look like style changes.

## Key Entities

Source audit, supplied sample (origin/channel/purpose), provisional voice observation with
counterevidence, optional user-reviewed profile, content-vs-style correction, protected draft.

## Success Criteria

Source methods and licenses are traceable. Reference is reachable only on supplied voice inputs
and ships in all supported payload layouts. All cases have reviewable expected behavior without
invented empirical thresholds. Existing55patterns/registry and safeguards stay intact. No persona
is generated for the owner in this task; efficacy requires later independent evaluation.

## Assumptions

This improves editing of AI drafts, not a new autonomous content generator or voice-cloning
identity service. Runtime/profile installation, publishing and persistent personal memory are out
of scope. Existing0.11.1source patch is preserved as the pre-feature baseline.
